# airbnb-clone-project
#Project Description
This project is a full-stack clone of the popular accommodation booking platform AirBnB. The goal is to build a functional web application that allows users to browse property listings, view detailed property information, and complete bookings. The project will cover frontend development, backend APIs, database design, and deployment.

Understand how to structure a complex web application

Develop skills in component-based frontend architecture

Figma Design Specifications

## Color Styles
- **Primary**: #FF5A5F (Airbnb Red - for CTAs, highlights, and brand elements)
- **Secondary**: #008489 (Teal - for secondary actions and accents)
- **Background**: #FFFFFF (White - for main background areas)
- **Text**: #222222 (Dark Gray - for primary text content)
- **Secondary Text**: #717171 (Medium Gray - for secondary information)
- **Border**: #DDDDDD (Light Gray - for borders and dividers)
- **Success**: #00A699 (Green - for success states)
- **Warning**: #FFB400 (Orange - for warnings and alerts)
- **Error**: #C13515 (Red - for error states)

## Typography
- **Primary Font Family**: Circular (Airbnb's custom font)
- **Fallback Font**: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- **Font Weights**: 
  - Book (400) - for body text
  - Medium (500) - for emphasis
  - Bold (700) - for headings
- **Font Sizes**:
  - H1: 32px (Circular Bold)
  - H2: 24px (Circular Bold)
  - H3: 20px (Circular Medium)
  - Body: 16px (Circular Book)
  - Small: 14px (Circular Book)
  - Caption: 12px (Circular Book)

## Importance of Identifying Design Properties

Identifying design properties in mockup designs is crucial for several reasons:

1. **Consistency**: Ensures all team members use the same colors, fonts, and spacing throughout the application
2. **Efficiency**: Developers can quickly implement designs without guessing specifications
3. **Brand Identity**: Maintains visual consistency with the brand guidelines and design system
4. **Scalability**: Creates a reusable design system that can be applied across different pages and components
5. **Collaboration**: Provides clear specifications for designers, developers, and stakeholders
6. **Quality Assurance**: Helps maintain design quality and reduces inconsistencies
7. **Accessibility**: Ensures proper contrast ratios and readable typography for all users
8. **Responsive Design**: Enables proper scaling and adaptation across different screen sizes
